# Pi 1.5 Compatibility Implementation Plan

**Goal:** Keep existing Grok UI/interaction while preserving Pi 1.5 streaming performance and Markdown transformer contracts.
**Architecture:** Retain existing prototype patches. Keep patch-local per-assistant render slots in a WeakMap; reuse Markdown and thinking components, updating text rather than rebuilding expensive state. Centralize transformer chaining with lazy context so live/restored metadata, streaming state and width remain correct.
**Scope approved:** User requested both primary fixes plus all audit follow-ups; chose in-place implementation. No remote publish/push. No extra agents requested; implementation and final review are inline.
**Constraints:** Display-only; unchanged message data, bubbles, fold behavior, native write/edit appearance. Host peer dependencies stay external. Missing transformer lists remain safe for old components.
